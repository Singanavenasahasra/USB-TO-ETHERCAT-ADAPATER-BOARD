# USB-to-EtherCAT Adapter Board

A compact hardware platform developed for interfacing USB systems with EtherCAT-based networks. The board was designed in KiCad with emphasis on clean circuit organization, efficient PCB routing, and practical hardware integration.

## Tools
- KiCad
- PCB Design & Layout
